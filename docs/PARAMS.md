# AgentSound parameter reference

Generated by `agentsound params --markdown`. Ranges are inclusive; enum params take the choice name as a string.

## amp (effect)

| param | range | default | unit | auto | help |
|---|---|---|---|---|---|
| `gain` | 0..10 | 6 |  | yes | Preamp gain (the gain knob), spread over the stages: 0-2 clean / edge of breakup, 3-5 crunch, 6-8 a singing lead, 9-10 saturated high gain. 6 dB + 5.4 dB per step in total (60 dB at 10). |
| `stages` | 1..4 | 3 |  |  | Cascaded preamp gain stages (whole number): 1 = a simple combo, 2 = a Plexi, 3 = a hot-rodded lead channel (default), 4 = modern high gain. More stages = smoother, more compressed, more sustain at the same gain. |
| `boost` | 0..30 | 0 | dB | yes | An overdrive pedal in front (Tube Screamer style, 0 = off): mid-hump drive (the lows pass clean, the mids above ~720 Hz clip), then a 5 kHz low-pass. 6-12 dB = the classic lead boost: tighter lows, focused singing mids. |
| `tight` | 20..500 | 90 | Hz | yes | High-pass before the first gain stage (the input coupling): 60-90 = full Plexi lows, 120-200 = tight (no farting low notes under heavy gain), 300+ = thin. |
| `bright` | 0..12 | 3 | dB | yes | Bright cap: a treble shelf (~1.2 kHz) before the first stage: more bite and pick attack. |
| `bass` | 0..10 | 5 |  | yes | Tone stack bass (log pot) - the stack is passive: it shapes, it never boosts. |
| `mid` | 0..10 | 5 |  | yes | Tone stack middle: 0 = the scooped metal mid, 6-8 = a mid-forward lead that cuts. |
| `treble` | 0..10 | 5 |  | yes | Tone stack treble. |
| `stack` | british|american | british |  |  | Tone stack values: british = Marshall (tighter, mid-forward), american = Fender Bassman (deeper mid scoop, rounder). |
| `presence` | 0..10 | 5 |  | yes | Power-amp presence (the feedback loop's treble, a shelf ~3.5 kHz): 0 = -7 dB, 5 = flat, 10 = +7 dB. |
| `resonance` | 0..10 | 5 |  | yes | Power-amp resonance / depth (the speaker's low resonance, a peak ~110 Hz): 0 = -6 dB, 5 = flat, 10 = +6 dB. |
| `master` | 0..10 | 5 |  | yes | Master volume: how hard the push-pull power stage is driven (-6 dB + 3 dB per step): 2-4 = preamp distortion only, 5-7 = the power amp joins in (thicker, compressed), 8-10 = a cranked Plexi. |
| `sag` | 0..1 | 0.3 |  | yes | Supply sag (tube rectifier): a loud note pulls the supply down - the power stage clips earlier and quieter, then recovers as the note rings (compression with a bloom). 0 = a stiff solid-state supply, 0.3 = a lead amp, 0.7-1 = spongy vintage. |
| `output` | -36..12 | 0 | dB | yes | Output level (after the power amp; a cranked amp sits around -16 dBFS RMS, peaks near -9 dBFS at 0 dB: +6 dB for a hot track). |
| `mix` | 0..1 | 1 |  | yes | Amp / DI blend: 1 = the amp only (default); below 1 the clean input (the DI, time-aligned with the oversampled amp path, at its input level) is mixed in: out = amp * mix + DI * (1 - mix). A bass rig (SVT-style DI + amp): 0.4-0.6 with 'tight' 150-300 - the DI carries the lows and the attack, the amp the growl. The DI is not scaled by 'output'. |

| `makeup` | -24..24 | 0 | dB | yes | Output gain after compression. |
| `automakeup` | off|on | off |  | yes | Adds makeup gain so a -10 dBFS peak comes out at about -10 dBFS again. |
| `mix` | 0..1 | 1 |  | yes | Parallel (New York) compression: 1 = fully compressed, 0.3-0.5 = dense but natural. |
| `detector` | peak|rms | peak |  |  | peak = fast and precise (drums), rms = smoother, program-dependent (buses, pads). |
| `keyhp` | 20..500 | 20 | Hz | yes | High-pass on the detector key so low end triggers less reduction (100-150 on a mix bus); 20 = off. |

| `bandq` | 0.2..8 | 0.7 |  |  | Band mode: width of the band (Q; 0.5-0.8 = 2 octaves: 1.2-4.5 kHz around 2.5 kHz, 2-4 = narrow). |

## convolver (effect)

| param | range | default | unit | auto | help |
|---|---|---|---|---|---|
| `ir` | 0..0 | 0 | path |  | The impulse response - a path, not a number (required): a WAV relative to assets/ ("samples/<pack>/...") or absolute. 1 channel = the same IR on both sides, 2 = stereo (L->L, R->R), 4 = true stereo (LL, LR, RL, RR). A list of files is one IR from their channels in order: [left, right] mono files, [left-input, right-input] stereo files (true stereo, e.g. Bricasti .L/.R pairs) or 4 mono files LL, LR, RL, RR (e.g. Lexicon 224XL V1.1.L, V1.1.R, V1.2.L, V1.2.R). Any sample rate (resampled). Find IRs: python -m agentsound find ir; ready-made returns and cabinets: the patches bus/ir_* and cab/*. |
| `mix` | 0..1 | 1 |  | yes | Dry/wet balance (equal power): 1 = wet only - return buses and cabinet IRs; 0.15-0.35 for a reverb IR as an insert |
| `gain` | -40..24 | 0 | dB | yes | Level of the wet signal (after 'normalize') |
| `predelay` | 0..500 | 0 | ms | yes | Delay before the IR (glides when automated); 10-40 ms keeps attacks clear of a hall. Adds to any silence at the start of the IR file (see 'start') |
| `lowcut` | 20..2000 | 20 | Hz | yes | High-pass on the wet signal (12 dB/oct); 20 = off. 150-300 keeps a reverb out of the bass |
| `highcut` | 1000..20000 | 20000 | Hz | yes | Low-pass on the wet signal (12 dB/oct); 20000 = off. Darkens bright rooms and plates |
| `width` | 0..2 | 1 |  | yes | Stereo width of the wet signal (mid/side): 0 = mono, 1 = as recorded, 2 = extra wide |
| `start` | 0..2000 | 0 | ms |  | Skips the head of the IR file: its silence before the direct sound, or the direct sound itself (the dry path already has it). File time (before 'stretch'); not automatable |
| `length` | 0..30 | 0 | s |  | Keeps at most this much of the IR after 'start' (a shorter tail, less CPU), faded out over its last quarter (<= 0.5 s); 0 = the whole IR (its tail once it has fallen 80 dB under its peak is always dropped). File time; not automatable |
| `stretch` | 0.5..2 | 1 | x |  | Resamples the IR: 2 = a room twice as large (twice as long, an octave darker), 0.5 = smaller and brighter; energy kept. Not automatable |
| `normalize` | off|on | on |  |  | on: the IR is scaled to unit energy (white noise comes out at its input level), so IRs from different packs sit at comparable levels; off: the file's own level (cabinet IRs made for unity gain). Not automatable |
| `reverse` | off|on | off |  |  | on: plays the IR backwards (after start / length): a swell that ends where the note was - reverse reverb; set 'length' to the swell time. Not automatable |
| `crossfeed` | 0..1 | 0 |  | yes | Feeds each input side into the other before the IR (wet path only; power-kept: a hard-panned or wide source keeps its return level, a centred one gains up to +3 dB at 1). A mono / 2-channel IR - one centred source recorded, L->L and R->R - leaves a hard-panned part with a one-sided room; 0.4-0.6 gives it a surrounding space that still leans to its side (pseudo true stereo: halls for panned orchestra sections, a band room for hard-panned guitars), 1 = mono in (every source excites the whole room alike). A 4-channel (true stereo) IR already answers both sides: keep 0. 0 = as recorded (bit-exact) |

| param | range | default | unit | auto | help |
|---|---|---|---|---|---|
| `freq` | 2000..16000 | 6500 | Hz |  | Where sibilance starts: the detector's high-pass and (split mode) the edge of the band that is turned down. Female / bright voices 6-8 kHz, male voices 4.5-6 kHz; harsh 'sh' / 'ch' 3.5-5 kHz. |

| `release` | 5..500 | 60 | ms | yes | Recovery: 40-100 ms; longer dulls the vowel after the consonant. |
| `mode` | split|wide | split |  |  | split: only the band above freq is turned down (the vowel stays bright); wide: the whole signal dips (gentler on the tone, audible as level on loud s). |
| `listen` | off|on | off |  | yes | Outputs the detected band (above freq) instead of the signal: tuning aid. |

## vocoder (effect, needs a sidechain)

| param | range | default | unit | auto | help |
|---|---|---|---|---|---|
| `mode` | classic|lpc | classic |  |  | classic = analog channel vocoder: 'bands' band-pass filters on the modulator open the same bands of the carrier (the Kraftwerk / Daft Punk robot; chords on the carrier = robot choir); lpc = talkbox: the modulator's vocal-tract resonances (running LPC) filter the carrier - smoother, most intelligible (Zapp, The Midnight) |
| `bands` | 8..40 | 20 |  |  | classic: number of bands, log-spaced over lo..hi: 8-12 = lo-fi 70s robot, 16-24 = classic and intelligible, 28-40 = smooth, almost natural |
| `lo` | 50..1000 | 100 | Hz |  | classic: centre of the lowest band |
| `hi` | 2000..16000 | 8000 | Hz |  | classic: centre of the highest band (speech has little above 8 kHz; 'unvoiced' and 'sibilance' add the air) |
| `bandwidth` | 0.5..2 | 1 |  | yes | classic: band width relative to the band spacing: 1 = neighbours cross at -3 dB, 0.5-0.7 = narrow, ringing, more robotic bands, 1.3-2 = broad, smooth, softer consonants |
| `attack` | 0.5..100 | 2 | ms | yes | How fast the vocoder opens on a syllable (envelope attack): 1-3 ms crisp consonants, 10-30 ms soft |
| `release` | 5..1000 | 15 | ms | yes | How fast it closes (envelope release, also the gate and the glide out of 'hold'; lpc: at least ~16 ms, its analysis window): 8-25 ms intelligible speech, 60-300 ms smeared and pad-like, 500+ ms washes |
| `shift` | -12..12 | 0 | st | yes | Formant shift: the carrier bands (classic) / the vocal tract (lpc) move against the analysis: -3..-6 = bigger, deeper robot, +3..+6 = smaller, cartoon voice; the pitch stays the carrier's notes |
| `emphasis` | 0..12 | 4 | dB/oct | yes | Treble lift of the modulator above ~800 Hz before it shapes the carrier: 3-6 = clear and present, 8-12 = bright, whispery, 0 = dark, muffled |
| `flatten` | 0..1 | 0.7 |  | yes | How much of the carrier's own spectral balance is evened out before the voice shapes it (classic: each band pulled towards the average band level, at most +-24 dB; lpc: running whitening filter), so the output follows the voice's spectrum: 0 = the carrier's timbre (a dark pad stays dark and mumbles), 0.7 = balanced, 1 = speech-like on any carrier |
| `unvoiced` | 0..1 | 0.5 |  | yes | Noise mixed into the carrier while the modulator is unvoiced ('s', 'f', 't', 'sh': detected from its high/low energy ratio), so consonants stay intelligible even on dark carriers; 0 = off |
| `sibilance` | 0..1 | 0.3 |  | yes | The modulator's own highs (above 5 kHz) passed through on unvoiced sounds: crisp 's' and 't' on top of the robot; 0 = off |
| `gate` | -90..-20 | -60 | dB | yes | Modulator level (dBFS) below which the vocoder closes: breaths and noise between words stay silent |
| `hold` | off|on | off |  | yes | Freeze: on keeps the current spectrum (the vowel being sung) and sustains it on the carrier while the modulator goes on; off follows the modulator again (gliding there over 'release', also into silence). Automate it for robot 'aaah' holds at phrase ends |
| `width` | 0..1 | 0.5 |  | yes | classic: stereo spread, alternate bands panned left / right (bands below ~150 Hz stay centred); 0 = the carrier's own stereo image |
| `order` | 8..40 | 24 |  |  | lpc: prediction order (vocal-tract detail): 12-16 = smooth, soft formants, 24 = natural, 32-40 = sharp, may whistle |
| `mix` | 0..1 | 1 |  | yes | Dry/wet: 1 = vocoder only, 0.1-0.3 = some of the plain carrier underneath |
| `output` | -24..24 | 0 | dB | yes | Output level. The vocoder follows the carrier and the modulator: speech at -18 dBFS active level (what agentsound.speech writes) keeps the carrier at about its own loudness (+-2 LU) |
